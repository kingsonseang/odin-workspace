# BUG-1056 — Details panel shows an outdated status after completing from the list

- **ID:** BUG-1056
- **Status:** Open
- **Reported:** 2026-10-16
- **Observed in:** Task list and task details panel
- **Environment:** Tasklane demo, Chrome on macOS, 1440×900 viewport
- **Frequency:** Every time

## Expected behavior

When a task is open in the details panel and its completion state changes elsewhere on the board, the details panel should reflect the current state immediately. The specification requires every representation of a task to stay synchronized.

## Actual behavior

After checking a task’s completion checkbox in the list, the row changes to **Done** and its checkbox changes to the reopen action. The open details panel continues to show **In progress** for the same task. Closing and reopening the panel shows the correct status.

## Steps to reproduce

1. Reset the demo data.
2. Select the task title **Fix mobile navigation overlap**.
3. Confirm the details panel shows **In progress**.
4. Leave the panel open.
5. Check the task’s checkbox in the list.
6. Compare the row with the status shown in the details panel.

## Impact

The same task appears to be in two different states at once. A user who checks the panel may act on outdated information, and the mismatch undermines confidence in the board’s status counts.

## Additional context

- The row badge and the summary count both change to reflect the completion.
- The panel updates correctly if it is closed and reopened.
- The mismatch is reproducible after the panel has been open for several minutes, not only immediately after opening it.
