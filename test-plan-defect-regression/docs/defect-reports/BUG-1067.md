# BUG-1067 — An existing task can be saved with a blank title

- **ID:** BUG-1067
- **Status:** Open
- **Reported:** 2026-10-20
- **Observed in:** Edit task form and task list
- **Environment:** Tasklane demo, Chrome on macOS, 1440×900 viewport
- **Frequency:** Every time

## Expected behavior

A task title is required in both create and edit forms. Clearing the title and saving should keep the form open and show a title validation error. The specification requires the same validation rules for creation and editing.

## Actual behavior

When editing an existing task, the title can be cleared and **Save changes** closes the form. The task then appears as a blank row. Opening its details shows no title. No validation message appears.

## Steps to reproduce

1. Reset the demo data.
2. Find **Add an empty state to the project list**.
3. Choose **Edit** for that task.
4. Clear the **Title** field.
5. Choose **Save changes**.
6. Inspect the row that previously represented the task.

## Impact

A required field can be removed, leaving the board with an unidentifiable task that is difficult to select or manage. This is inconsistent with the create flow, where an empty title is rejected.

## Additional context

- The same blank title is rejected when creating a new task.
- Whitespace-only titles also save when editing.
- Existing automated tests do not cover this path.
